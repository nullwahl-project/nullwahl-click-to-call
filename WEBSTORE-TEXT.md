# Entwurf Chrome Web Store

**Titel:** Nullwahl – Click-to-Call

**Kurztext:** Erkennt Telefonnummern mit führender Null auf Webseiten und öffnet sie in deinem Softphone.

**Beschreibung:** Nullwahl macht deutsche Telefonnummern mit führender Null anklickbar, auch mit Leerzeichen, Schrägstrichen und Durchwahlen. Auf Wunsch kannst du internationale Nummern mit Pluszeichen aktivieren. Die Erweiterung übergibt Rufnummern via `tel:` an Linphone oder ein anderes im System eingerichtetes Softphone. Telefonnummern und Webseiteninhalte bleiben lokal. Keine Werbung, kein Tracking, keine Serververbindung der Erweiterung.

**Berechtigungen:** `storage` – ausschließlich für die lokal gespeicherte Option internationale Nummern. Ausführung auf HTTP/HTTPS – um Telefonnummern in Webseiten zu erkennen.
